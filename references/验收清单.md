# 交付前验收清单

> 交付（或请用户预览）前逐项过一遍。视觉类按 `风格-科技蓝HUD.md` §14 的完整版执行；本文件是跨风格的最小集合 + 交互自测。

## A. 渲染与布局

- [ ] 1920×1080 设计，任意窗口尺寸完整显示：不裁切、不变形、无横向滚动条。
- [ ] 栅格对齐：同行 panel 等高、同列等宽；间距 10–16px；左右安全边距 ≥ 22px。
- [ ] 无文字溢出/截断（该截断的加 `text-overflow:ellipsis` + title）；数字等宽（`tabular-nums`）不抖动。
- [ ] 图表无白色绘图区、无 3D 柱、无饼图阴影；轴标签 ≥ 11px。

## B. 视觉（按所选风格校准）

- [ ] 整屏一个视觉焦点；发光元素 ≤ 5 处、单处 ≤ 12px。
- [ ] 主色一系贯穿；暖色/强调色占比 ≤ 10%；单图分类色 ≤ 7。
- [ ] 面板 1px 边框、圆角 ≤ 4px、无厚重投影（亮色风格阴影按其规范）。
- [ ] 对比度：正文 ≥ 4.5:1，大数字 ≥ 3:1；语义色全部配文字/箭头，非纯颜色区分。
- [ ] 装饰元素（星空/光轨/角标）不遮挡文字与数据点。

## C. 内容

- [ ] 一屏一结论：3 秒能读出整屏在讲什么；版块全部能回答一个具体问题。
- [ ] 指标口径表已列；示例数据与口径自洽（分项加总、环比、占比能对上）。
- [ ] 全屏时间一致；无真实人名/敏感明文；未接入数据的版块显示"数据接入中"而非 0。
- [ ] 多方案间同一指标口径、数字一致；总览 md 的对比表与各屏实际内容一致。

## D. 交互（浏览器实测）

- [ ] 数字滚动入场正常（`data-num` 元素）。
- [ ] 双击空白 → 全屏；再双击 → 退出；全屏态布局不散架。
- [ ] 双击面板标题/KPI 名 → 编辑生效，Esc 还原；`data-edit-key` 元素刷新后回填。
- [ ] 「看板导读」：自动开讲或按钮可开；逐站挖孔套住目标、卡片不遮高亮区；编辑导读文案保存后刷新仍生效；「恢复默认」可用；键盘 ←/→/Enter/Esc 可用。
- [ ] 地图/联动类：地标 ↔ 卡片点击联动正常（双方 `.on` + 虚线连线）；拖动光点时连线/飞线实时跟随，松手后刷新位置保留（localStorage）；「重置」可回到初始位置；容器尺寸变化后 16:9 适配不出位。
- [ ] 含地图页面：底图来源已确认（用户提供素材 / 回退渐变示意并标注「底图待替换」）；光点坐标体系与底图投影一致（换过底图的 `lsVersion` 已 +1）。
- [ ] 缩放窗口至非 16:9（如 1366×768 笔记本）再走一遍导读，不出位。

## E. 交付物完整性（多方案模式）

- [ ] 输出目录含：基座五件套（css/js/编辑/导读/地图）+ `00-总览与选型建议.md` + 每方案 `大屏-方案N-主题.html` +（推荐）每方案 `方案N-主题.md`。
- [ ] 若工作区已有基座/规范，生成页引用的是工作区版本（不是技能自带副本），五件套文件名与工作区惯例一致。
- [ ] 每个方案 HTML 的 `window.TOUR` 站清单与方案 md 的交互站清单一致。
