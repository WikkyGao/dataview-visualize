# 设计规范：科技蓝 HUD 大屏视觉风格

> 适用范围：深色科技风数据大屏的**视觉语言**（色彩、光效、组件、图表、动效）。
> 不涉及：屏幕内容规划、指标选取、版块划分、业务叙事。
> 版本：v1.0 | 2026-10-29

---

## 1. 风格定位

**深空蓝底 + 冷青主光 + 半透明 HUD 面板 + 晶体主视觉**。

| 关键词 | 具体指向 |
|---|---|
| 深空 | 近黑的深蓝背景，中心有呼吸感的辉光，四周压暗 |
| HUD | 细线边框、四角角标、切角标题栏、虚线网格、坐标刻度 |
| 晶体 | 棱锥/钻石状主体，半透明渐变面，边缘高光 |
| 光轨 | 椭圆平台环、轨道环、流动光点、扫描线 |
| 冷色高对比 | 青蓝为骨架，白为数据，黄/绿/红只做强调 |

整体气质：**冷静、精密、可远观**。远看是一个发光的中心体 + 一圈数据框；近看每个框都有细密的刻度与角标。

---

## 2. 设计原则

1. **一个发光中心**：整屏只允许一个视觉焦点（通常是中央主视觉），其余区块亮度必须低于它。
2. **面板退后，数据向前**：面板透明度低、边框细；数字最大、最亮。
3. **光只给焦点**：外发光只用于当前值、告警、主视觉；普通卡片不加光。
4. **冷底暖点**：大面积冷色，暖色（黄/橙）只用于关键数值和警示，占比不超过 10%。
5. **线要细、角要利**：1px 线、2–4px 圆角、切角与直角为主，避免大圆角和厚重投影。

## 3. 色彩系统

### 3.1 背景色

| 令牌 | 色值 | 用途 |
|---|---|---|
| `--bg-0` | `#040B18` | 最外层兜底底色 |
| `--bg-1` | `#071A33` | 页面基础深蓝 |
| `--bg-2` | `#0A2A50` | 中心辉光区 |
| `--bg-glow` | `#0E5A8A` | 主视觉背后的柔光 |
| `--bg-bottom` | `#0A3F6B` | 底部极光带，透明度 ≤ 25% |

背景构成：`radial-gradient(ellipse at 50% 42%, #0E4C86 0%, #082A4E 38%, #04101F 78%, #030A14 100%)`，底部叠一条青色极光带。

### 3.2 主色（青蓝）

| 令牌 | 色值 | 用途 |
|---|---|---|
| `--cyan-1` | `#35D6FF` | 主强调、角标、高亮描边 |
| `--cyan-2` | `#1AA7E0` | 主色、图标、进度填充 |
| `--cyan-3` | `#0B6FA8` | 深色填充、渐变的暗端 |
| `--cyan-soft` | `rgba(53,214,255,.12)` | 标签底、选中底 |

### 3.3 语义色

| 令牌 | 色值 | 含义 |
|---|---|---|
| `--ok` | `#2BE3A4` | 正常、上升、已闭环 |
| `--warn` | `#FFC24A` | 关注、临期、强调数值 |
| `--danger` | `#FF5D73` | 严重、下降、超时 |
| `--info` | `#5AA9FF` | 中性信息、辅助系列 |

> 语义色永远配合箭头、图标或文字，不允许只靠颜色区分。

### 3.4 图表分类色（按顺序取用）

`#35D6FF` → `#21D3C4` → `#5AA9FF` → `#8B7BFF` → `#FFC24A` → `#FF7AB6` → `#A8E05F`

- 同一图表系列不超过 7 色；超过 7 类必须合并为"其他"。
- 分类色饱和度统一压低 10%，避免抢主色。

### 3.5 用色配比

| 层级 | 占比 | 内容 |
|---|---|---|
| 底 | 60% | 深蓝背景、面板底 |
| 主 | 30% | 青蓝线条、图标、图表主体 |
| 点 | 10% | 白数字、黄/绿/红强调 |

## 4. 渐变、光效与材质

### 4.1 渐变

| 类型 | 写法 | 用途 |
|---|---|---|
| 背景辉光 | 径向，中心 `#0E4C86` → 边缘 `#030A14` | 整屏底 |
| 数字渐变 | 线性 180°，`#FFFFFF` → `#BFEBFF` | 大号指标数字 |
| 面板底 | 线性 180°，`rgba(10,44,80,.62)` → `rgba(6,20,40,.72)` | 面板 |
| 标题条 | 线性 90°，`transparent` → `rgba(53,214,255,.18)` → `transparent` | 面板标题栏 |
| 面积图 | 线性 180°，`rgba(53,214,255,.38)` → `rgba(53,214,255,0)` | 折线下面积 |
| 进度条 | 线性 90°，`#1AA7E0` → `#35D6FF` → `#21D3C4` | 条形/环形填充 |

同屏渐变方向不超过 2 种（竖向 + 横向），避免杂乱。

### 4.2 光效

| 类型 | 参数 | 用途 |
|---|---|---|
| 外发光 | `0 0 12px rgba(53,214,255,.35)` | 角标、当前值、关键节点 |
| 内发光 | `inset 0 0 24px rgba(53,214,255,.10)` | 面板内侧，制造玻璃感 |
| 文本光 | `0 0 18px rgba(53,214,255,.55)` | 仅主标题与中央大数字 |
| 呼吸光 | 3s 循环，透明度 .55 → 1 | 主视觉、告警点 |

发光强度上限：单屏同时发光元素 ≤ 5 处。

### 4.3 材质

- **玻璃**：`background: rgba(9,38,70,.55)` + `backdrop-filter: blur(2px)`。
- **金属切边**：标题栏两端用 `clip-path` 做 45° 切角，切边描 1px `rgba(120,230,255,.6)`。
- **描边**：普通 1px `rgba(70,190,255,.28)`；强调 1px `rgba(90,225,255,.75)`。

## 5. 字体与字号层级

### 5.1 字体

| 用途 | 字体 | 回退 |
|---|---|---|
| 数字 | DIN 2014 / Bahnschrift / Rajdhani | `DIN Alternate, "Helvetica Neue", Arial` |
| 中文 | 思源黑体 / 优设标题黑（标题） | `"PingFang SC", "Microsoft YaHei"` |
| 英文标签 | Rajdhani / Barlow Condensed | 同上 |

数字必须启用等宽数字：`font-variant-numeric: tabular-nums`。

### 5.2 层级（以 1920×1080 为基准）

| 层级 | 字号 | 字重 | 字距 | 用途 |
|---|---|---|---|---|
| 屏标题 | 34px | 700 | 6px | 顶部主标题 |
| 面板标题 | 18px | 600 | 2px | 卡片标题 |
| 主指标 | 44–48px | 700 | 0 | 核心数字 |
| 次指标 | 26–28px | 600 | 0 | 次级数字 |
| 单位/后缀 | 12–14px | 500 | 1px | %, 个, min |
| 正文 | 13px | 400 | .5px | 说明文字 |
| 图例/轴标签 | 11–12px | 400 | .5px | 图表标注 |
| 注释 | 11px | 400 | 0 | 数据截止、口径 |

标题统一加 `letter-spacing`，数字不加字距（避免读数断裂）。

## 6. 版式与栅格

| 项 | 规范 |
|---|---|
| 画布 | 1920×1080，导出 1:1；超宽屏按高度等比缩放并居中 |
| 外边距 | 左右 28px，上下 24px |
| 顶部标题区 | 高 88px（含装饰翼与日期时间） |
| KPI 行 | 高 112–120px，6 等分，间距 16px |
| 内容区 | 12 列栅格，列宽 140px，槽宽 16px |
| 面板间距 | 16px；同组内 12px |
| 面板内边距 | 18px 20px；标题栏到内容 8px |
| 圆角 | 面板 2–4px；标签 2px；按钮 2px；不使用胶囊大圆角 |
| 分割线 | 1px `rgba(90,200,255,.14)`，可带 40px 渐变淡出 |

层级建议：**标题区 → KPI 行 → 主视觉 + 两侧图表 → 底部明细**，中央区块宽度不小于总宽 40%。

## 7. 组件规范

### 7.1 HUD 面板

```
border: 1px solid rgba(70,190,255,.28)
background: linear-gradient(180deg, rgba(10,44,80,.62), rgba(6,20,40,.72))
box-shadow: inset 0 0 24px rgba(53,214,255,.10)
```

- 四角角标：14×14px，2px 线，`#5AE1FF`，仅描 L 形两条边，外发光 8px。
- 标题栏：高 36–40px；左侧 18×18 线性图标（描边 1.5px，颜色 `--cyan-1`）；标题 18px；右侧装饰斜线组（3 条，透明度 .35）。
- 标题栏底部一条 1px 渐变线，中心最亮、两端淡出。

### 7.2 KPI 卡

| 元素 | 规格 |
|---|---|
| 高度 | 96–118px |
| 图标区 | 左 52px，图标 24px，线性描边，背后加 `rgba(53,214,255,.10)` 圆形光晕 |
| 指标名 | 13px，`--text-2` |
| 数值 | 40px，数字渐变，`tabular-nums` |
| 环比 | 12px，上升 `--ok` + ▲，下降 `--danger` + ▼ |
| 分隔 | 卡内右侧 1px 竖线 `rgba(90,200,255,.15)`，仅组内使用 |

### 7.3 标签 / 图例 / 状态点

- 标签：高 20px，左右内边距 8px，背景 `rgba(53,214,255,.12)`，1px 边框 `rgba(53,214,255,.35)`，12px 文字。
- 图例：8px 圆点 + 12px 文字；横向间距 16px，纵向 8px。
- 状态点：6–8px 实心圆 + 同色 6px 外发光；异常状态加 1.5s 呼吸。

### 7.4 时间轴 / 流程条

- 节点：10px 空心圆，2px 描边；当前节点实心 + 外圈 3px 光圈。
- 连线：1px，左端 `rgba(53,214,255,.20)` → 右端 `rgba(53,214,255,.65)`。
- 标签在上（12px），数值在下（20px），节点垂直居中。
- 阶段间可加 45° 斜线分隔，营造机械感。

### 7.5 进度条 / 条形

- 轨道高 8–10px，`rgba(255,255,255,.08)`，圆角 = 高度一半。
- 填充：横向渐变 `#1AA7E0 → #35D6FF`，末端 2px 高光点。
- 进度 > 90% 转 `--ok` 渐变；超时项用 `--danger` 并在末端加脉冲点。

### 7.6 按钮 / 交互态

- 默认：透明底 + 1px 青边 + 青字；悬停：底 `rgba(53,214,255,.12)` + 外发光 8px。
- 选中：底 `rgba(53,214,255,.18)`，边框提亮到 `.75`，左侧加 2px 竖条。
- 不用实心高饱和填充按钮（会破坏整体冷调）。

## 8. 图表规范

| 图表 | 关键规格 |
|---|---|
| 折线 | 线宽 1.5px，主色；面积渐变 alpha .38 → 0；节点 4px 白点 + 6px 光晕，仅标首尾与峰值 |
| 柱/条 | 宽 8–12px，圆角 2px；渐变填充；同组柱间距 ≥ 6px；不用 3D 柱 |
| 环形 | 环宽 6–8px，底环 `rgba(255,255,255,.08)`；外圈加 1px 细描边；中心放数字 |
| 饼/环图 | 扇区间留 2px 底色描边；标签引线 1px，端点 3px 圆点；占比 <3% 合并 |
| 雷达 | 4 层虚线网格，轴线 1px；填充 alpha .18，描边 1.5px |
| 仪表 | 180° 弧，刻度每 10 一格；指针 2px；中心数字最大 |
| 网格 | 虚线 `1px rgba(120,200,255,.10)`，横向 5–6 条，不画竖网格（除时间轴刻度） |
| 轴文字 | 11–12px，`#7FA8C9`，不加粗 |

图表背景一律透明，不画白色绘图区，图表与面板共用同一深底。

## 9. 3D 与装饰元素

| 元素 | 规格 | 约束 |
|---|---|---|
| 主视觉晶体 | 棱锥/钻石，2–3 个渐变面，边缘 1px 高光 | 高度不超过内容区 55% |
| 平台环 | 2–3 层椭圆，1px 描边，内圈加柔光 | 与晶体底部对齐，做"悬浮"感 |
| 轨道环 | 1px 虚线椭圆，倾斜 15–25°，带 1–2 个光点 | 不遮挡数据标签 |
| 漂浮碎片 | 6–12 个小三角/菱形，透明度 .2–.5 | 分布避开文字区 |
| 星点 | 40–80 个 1px 点，透明度 .15–.5 | 静态为主，缓慢漂移 |
| 标题翼 | 左右对称折线，45° 切角，1px 描边 + 渐变填充 | 宽度不超过屏宽 30% |
| 扫描线 | 1px 横向亮线，6s 自上而下 | 仅用于主视觉区 |

所有 3D/装饰元素**不承载数据**，不参与读数，不使用写实材质与强反光。

## 10. 动效规范

| 动效 | 时长/曲线 | 说明 |
|---|---|---|
| 数字滚动 | 800ms，`cubic-bezier(.22,.61,.36,1)` | 从旧值滚到新值，不逐位跳动 |
| 面板入场 | 400ms，上移 12px + 淡入 | 依次延迟 60ms |
| 折线绘制 | 1200ms | 从左至右描边，面积同步淡入 |
| 环形/进度 | 1000ms | 从 0 到目标值 |
| 呼吸光 | 3000ms 循环 | 透明度 .55 ↔ 1 |
| 光点巡游 | 8–20s 循环 | 沿轨道匀速，不加速 |
| 数据刷新 | 数值变化时闪一次 600ms 高亮 | 仅变化项，不平移布局 |

禁止：闪烁频率 > 3Hz、整屏位移、无限旋转文字、弹跳式缓动。

## 11. 可访问性与投屏校验

- 正文对比度 ≥ 4.5:1，大号数字 ≥ 3:1；不用纯黑 `#000` 作底。
- 语义色必须配图标/箭头/文字；色弱模式下仍可读。
- 投屏校验：亮度 70% 环境下，`--text-3` 仍可辨认；红色在投影偏橙时可辨。
- 数字使用等宽数字，刷新时不抖动。
- 关键结论字号 ≥ 28px，保证 5 米外可读。

## 13. Do / Don't

**Do**

- 一个大焦点，其余压暗。
- 细线、切角、角标，营造仪表感。
- 数字大而亮，标签小而灰。
- 黄/绿/红只点关键值。
- 图表透明底，与面板融为一体。

**Don't**

- 满屏发光、每个卡片都加光晕。
- 彩虹配色、超过 7 个分类色。
- 大圆角卡片 + 厚重投影（是后台风格，不是大屏风格）。
- 3D 元素压住数据或承载读数。
- 大面积高饱和红/绿（投影后刺眼且失真）。
- 花哨入场动画、循环旋转文字。

## 14. 验收清单

- [ ] 全屏只有 1 个视觉焦点，且为中央主视觉。
- [ ] 发光元素 ≤ 5 处，单处外发光 ≤ 12px。
- [ ] 主色只用了青蓝一系，暖色占比 ≤ 10%。
- [ ] 面板边框 1px，圆角 ≤ 4px，无重投影。
- [ ] 主指标字号 ≥ 40px，正文 ≥ 12px，轴标签 ≥ 11px。
- [ ] 数字为等宽数字，刷新不抖动。
- [ ] 语义色均配有图标或文字。
- [ ] 图表无白色绘图区、无 3D 柱、无饼图阴影。
- [ ] 装饰元素不遮挡任何文字与数据点。
- [ ] 1920×1080 与 3840×2160 下栅格与字号比例一致。
