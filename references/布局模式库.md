# 布局模式库（1920×1080 大屏）

> 只描述结构骨架，不含业务内容。选型依据：受众 × 叙事 × 主视觉素材，详见 SKILL.md 的确认环节。
> 以下栅格参数与 `assets/大屏基座.css` 对齐：头部 96px、KPI 行 100px（可覆盖列数）、底部图例行 30px + ticker 38px、面板间距 10–12px、左右安全边距 22–28px。

## 选型速查

| 模式 | 一句话骨架 | 适合的叙事 | 主视觉素材要求 | 成本 |
|---|---|---|---|---|
| L1 经典驾驶舱 | 中央主视觉 + 两侧图表翼 | 一个综合结论 | 3D 体 / 环 / 雷达 | 低 |
| L2 分层分域看板 | 行=层级，列=业务域，矩阵网格 | 多受众同屏、横竖两条读法 | 无（靠结构） | 中 |
| L3 中心地图 | 地图占核心，地标↔卡片联动 | 空间分布、区域对比 | 地图底图 + 地标数据 | 中高 |
| L4 流程主轴 | 泳道/流水线贯穿全屏 | 过程流转、瓶颈督办 | 流程阶段数据 | 中 |
| L5 实时态势 | 事件流为主，攻击/链路图辅助 | "正在发生"的紧张感 | 实时事件源 | 高 |
| L6 对象矩阵 | 卡片墙/矩阵，一对象一卡 | 以对象为主体的档案/清单 | 对象清单数据 | 中 |
| L7 左右分区 | 左管理右结果（或左总右分） | 两条对等主线 | 无 | 低 |

## L1 经典驾驶舱

```
┌────────────── 头部标题 ──────────────┐
│ KPI × 6~8（结论层）                  │
│ ┌─────┐ ┌─────────┐ ┌─────┐ │
│ │图表 │ │ 中央主视觉│ │图表 │ │   ← 中列宽度 ≥ 40%
│ │翼列 │ │(环/雷达/3D)│ │翼列 │ │
│ └─────┘ └─────────┘ └─────┘ │
│ 明细行（可选） / 图例 / ticker       │
└────────────────────────────────────┘
```

- 三段式栅格常取 `1fr / 1.6fr / 1fr`；中列放唯一视觉焦点。
- KPI 每张 = 主指标 + 一个次要指标或环比，不放裸数字堆。
- 适合汇报场景、数据要求最低的先导屏。

## L2 分层分域看板

```
┌── 头部 ────────────────────────────┐
│ [总览] KPI 行                        │   ← 行 0
│ [层标] ┌─列头A─┬─列头B─┬─列头C─┐    │
│ [决策] │ 卡片  │ 卡片  │ 卡片  │    │   ← 行 1
│ [业务] │ 卡片  │ 卡片  │ 卡片  │    │   ← 行 2
│ [一线] │ 卡片  │ 卡片  │ 卡片  │    │   ← 行 3
│ 图例 / ticker                       │
└────────────────────────────────────┘
```

- 左侧窄轨（56px 竖排层标）+ 三列内容，形成"横读=层级、竖读=业务域"两条读法。
- 网格实现：外层 `display:grid`，行 1fr 等分；允许某格跨行（如把行 1-2 的中列合并成一张大卡）。
- 层标可点击隐藏/显示对应行（`grid-template-rows` 收缩为 0）。
- 适合多受众共用的运营主屏；没有强主视觉时靠结构取胜。

## L3 中心地图

```
┌── 头部 ────────────────────────────┐
│ KPI 行                              │
│ ┌───── 地图主视觉（整块面板）─────┐ │
│ │[节点卡列]              ●─飞线─● │ │   ← 卡片叠放在地图上层，
│ │(绝对定位    地标与卡片联动        │ │      不单独占地图外一列
│ │ 左上角)                          │ │
│ └────────────────────────────────┘ │
│ 明细行 / ticker                     │
└────────────────────────────────────┘
```

- **节点卡列叠放在地图面板上层**（绝对定位在左上，盖住地图西部/空白区），不占地图外一列；卡片用半透明深色 HUD 底，与地图融为一体。
- 光点地标（脉冲）支持**拖拽微调**（位置存 localStorage）、**光点↔卡片虚线连线**、**光点间飞线弧**——能力由 `assets/大屏地图.js` 提供，接入写法见 `地图板块.md` §2。
- 地图高度铺满内容区，宽度按 16:9 等比推算，超出可视区左右居中裁切。
- 地标 ↔ 叠放卡联动：点击同高亮（`.on`）+ 虚线连线；飞线用 SVG 二次贝塞尔弧 + `stroke-dasharray`。
- **底图素材先问用户**（图片 / GeoJSON / 回退渐变示意），投影换算与 CSS `background-size` 严格对应；规则见 `地图板块.md` §1。
- 适合有地理/区域维度的对象分布叙事。

## L4 流程主轴

```
┌── 头部 ────────────────────────────┐
│ KPI 行                              │
│ ┌── 六段流水线（分段条 + 段量）──┐  │   ← 主轴
│ ├── 上：进度条段宽=占比           │  │
│ ├── 下：配套趋势图（柱/线）        │  │
│ └── 段间箭头/斜线分隔，卡点标红     │  │
│ 队列 / 明细行                       │
└────────────────────────────────────┘
```

- 分段条：`flex` 等缝排列，段宽=占比，颜色按阶段渐进或语义。
- 每段必须可读：段名 + 数量 +（可选）停留时长；卡点段加警示色。
- 适合"一条主线看到底"的过程叙事。

## L5 实时态势

```
┌── 头部 ────────────────────────────┐
│ KPI 行（今日量级）                  │
│ ┌─事件流/链路图（大）─┬─队列/排行─┐ │
│ │ 滚动事件 / 阶段链路 │ 待办队列   │ │
│ └────────────────────┴──────────┘ │
│ ticker（实时事件轮播，必配）         │
└────────────────────────────────────┘
```

- ticker 轮播：内容渲染两份实现无缝循环（CSS `marquee` 平移 -50%）。
- 等级徽标（高/中/低）用边框色 + 文字双编码，不靠颜色单通道。
- 适合重保/应急/值班场景。

## L6 对象矩阵

```
┌── 头部 ────────────────────────────┐
│ 筛选/汇总行（按维度聚合的统计）      │
│ ┌─卡─┬─卡─┬─卡─┬─卡─┐            │
│ ├─卡─┼─卡─┼─卡─┼─卡─┤ 对象矩阵    │
│ └─卡─┴─卡─┴─卡─┴─卡─┘            │
│ 明细 / ticker                       │
└────────────────────────────────────┘
```

- 一对象一卡：对象名 + 综合分/状态 + 2~3 个关键子指标；状态用左色条表达。
- 卡片数量 4~12 张；超出时选 TOP N + 「更多」提示，不缩字号硬塞。
- 适合"我的资产/我的系统"这类归属视角。

## L7 左右分区

```
┌── 头部 ────────────────────────────┐
│ KPI 行                              │
│ ┌─左列（域A）──┬─右列（域B）──┐     │
│ │ 卡 / 卡      │ 卡 / 卡      │     │
│ └──────────────┴──────────────┘    │
│ 图例 / ticker                       │
└────────────────────────────────────┘
```

- 两列各配列头；等宽或按内容 0.9fr/1.1fr。
- 最省事的骨架，适合内容量均衡的两条主线。

## 通用组装规则

1. **一个发光中心**：整屏只允许一个视觉焦点；无主视觉的模式（L2/L7）焦点让位给最大的 KPI 数字。
2. **列头/层标可隐藏**：点击列头隐藏整条列头带，下方面板上移；右上角出现「显示列头」恢复。
3. **每格一张 panel**：panel 内部自由排版（grid/flex），但同一行 panel 等高、同列等宽。
4. **行高比**：三行内容常见 `1fr / 1fr / 1.28fr`（一线行信息密度大，略高）。
5. ** ticker/图例**：底部两行是标配；图例顺序固定（正常 → 关注 → 严重 → 中性）。
