# 风格菜单（运行时和用户确认用）

> 科技蓝 HUD 是默认主推（本技能资产即按它构建）；其余风格通过替换 `:root` 令牌 + 背景层实现，骨架（基座类名、栅格、交互 JS）不变。
> 确认环节把本菜单提炼成 AskUserQuestion 选项：风格名 + 一句气质描述。

深空蓝底 + 冷青主光 + 半透明 HUD 面板。冷静、精密、可远观。
完整规范见 `风格-科技蓝HUD.md`（色彩令牌、字级、栅格、组件、图表、动效、验收清单）。

## S2 碳黑极简

近黑灰底、单高亮色（青或琥珀二选一）、无光效、细白线。克制、工程感。
要点：去掉基座的辉光与角标（`.panel::before` 置空），边框统一 `rgba(255,255,255,.12)`，唯一强调色只给当前值与告警。

```css
:root{
  --bg-0:#0A0C10; --bg-1:#11141A; --bg-2:#171B23;
  --cyan-1:#4CC3FF; --cyan-2:#2E9BD6; --cyan-3:#1E6E99;
  --text-1:#F2F4F8; --text-2:#B4BCC8; --text-3:#6B7482;
  --ok:#3DDC97; --warn:#F5B942; --danger:#F0566A; --info:#6FA8FF;
}
```

## S3 亮色商务浅底

浅灰白底 + 深蓝主色 + 卡片白底细阴影。适合白天会议室、领导层打印/截图。
要点：背景改浅色渐变，panel 改白底 + `box-shadow:0 2px 8px rgba(30,60,100,.10)`；文字反转（深字浅底）；语义色加深保对比（正文对比度 ≥ 4.5:1）；数字渐变改纯色。

```css
:root{

  --cyan-1:#1668DC; --cyan-2:#0F4FA8; --cyan-3:#0A3775;

  --ok:#0E9E6E; --warn:#C77F0A; --danger:#D6455D; --info:#3B82D6;
}
```

## S4 政务暖金

深红棕/深紫底 + 金色主光。庄重、仪式感，适合政务汇报与成果展示。
要点：主色换金色系（`#F5C542` 主光、`#B8860B` 暗端），背景径向中心偏暖（`#5A2A2A`/`#3A1030` 系），角标与标题翼随主色；语义色保持绿/黄/红但整体加暖。

```css
}
```

## S5 深空紫霓虹

深紫底 + 紫青双主光。炫、科技发布会感。
要点：主光 `#A78BFF` + 副光 `#4CE0D2`，双强调色分工（紫=结构/标题，青=数据/高亮）；发光上限依旧 ≤ 5 处，防止霓虹泛滥。

```css
:root{
  --bg-0:#0B0716; --bg-1:#150D28; --bg-2:#1E1238;
  --cyan-1:#A78BFF; --cyan-2:#7C5CE0; --cyan-3:#4A2F9E;
  --text-1:#F0EBFF; --text-2:#C0B2E8; --text-3:#7E6FA8;
  --ok:#3DE8C2; --warn:#FFC24A; --danger:#FF6A8A; --info:#5AB8FF;
}
```

## 换风格的三步法（骨架不动）

1. **替换令牌**：整屏颜色全部引用 `var(--…)`，换 `:root` 即全局变色；检查没有硬编码色值残留（基座自带的 rgba 强调色可保留低调中性灰蓝）。
2. **调整背景层**：`.stage` 的径向渐变端色、`.stars`、`.stage::before` 极光带按新风格改/删；亮色风格删星空与辉光。
3. **校准对比度**：正文 ≥ 4.5:1，大数字 ≥ 3:1；投影环境亮度 70% 下 `--text-3` 仍可辨认。

## 全风格通用反模式（验收会拦）

- 满屏发光 / 每张卡片都加光晕；发光元素 > 5 处。
- 彩虹配色、单图 > 7 个分类色。
- 大圆角卡片 + 厚重投影（后台风格，不是大屏风格）。
- 大面积高饱和红/绿（投影刺眼失真）。
- 3D/装饰元素压住数据、承载读数。
- 花哨入场动画、循环旋转文字、闪烁 > 3Hz。
