# 交互能力接入指南（双击编辑 + 看板导读 + 地图光点）

> 三个能力都在 `assets/` 基座五件套里，随 HTML 同目录引用即可，页面无需写实现代码。地图光点的完整接入见 `地图板块.md`，本文件只管引用顺序与共性。

## 1. 基座五件套与引用顺序

生成页面的 `<head>` / `<body>` 固定引用：

```html
<head>
  <link rel="stylesheet" href="大屏基座.css">
  <style> /* 页面专属样式，可覆盖基座（如 .kpis 列数） */ </style>
</head>
<body>
  …
  <script src="大屏基座.js"></script>   <!-- 缩放/全屏/时钟/数字滚动 -->
  <script> window.TOUR = { … }; </script>  <!-- 先定义配置 -->
  <script> window.DVMAP = { … }; </script> <!-- 仅含地图的页面 -->
  <script src="大屏编辑.js"></script>    <!-- 模块标题双击编辑 -->
  <script src="大屏导读.js"></script>    <!-- 分步导读引擎 -->
  <script src="大屏地图.js"></script>    <!-- 地图光点板块（仅含地图的页面） -->
</body>
```

顺序约束：`window.TOUR` / `window.DVMAP` 必须在对应 js 之前定义；`大屏基座.js` 先于所有（DOM 与缩放就绪）。

## 2. 双击编辑（大屏编辑.js）

- 默认生效对象：`.panel-h h2`（面板标题）、`.kpi .n`（KPI 名）、`header h1`（屏标题）、一切带 `data-editable` 的元素。
- 交互：双击进入（自动全选）→ Enter / 失焦保存 → Esc 还原进入前文案。已阻止冒泡，不会触发基座的双击全屏。
- 持久化（可选）：给元素加 `data-edit-key="唯一键"`，文案存 localStorage（key 含页面标题），刷新自动回填。不加则仅当场生效。
- 自定义可编辑区：任意元素加 `data-editable` 即纳入。
- 注意：编辑目标是纯文本/内联 HTML；不要把含子组件的容器设为可编辑。

## 3. 看板导读（大屏导读.js）

### 配置（写在页面里）

```html
<script>
window.TOUR = {
  autostart: true,        /* 加载 600ms 后自动开讲；false 则只留右上角按钮 */
  btnText: '看板导读',
  lsVersion: 1,           /* 页面结构改版、站号错位时 +1 弃用旧文案 */
  steps: [
    {sel: null,      t: '开篇：一屏一句话', d: '整屏叙事与两条读法…'},        // 不高亮
    {sel: '#kpiBand', t: '第 1 层｜总览',   d: 'KPI 行每张 = 主指标 + 环比…'},
    {sel: '.main-grid', exclude: ['#bigMap'], t: '…', d: '…'}                // exclude 再挖掉一块
  ]
};
</script>
```

### step 字段

| 字段 | 必填 | 说明 |
|---|---|---|
| `sel` | 否 | CSS 选择器（在 `#stage` 内查询）；缺省或找不到 → 该站只弹卡不高亮（适合开篇/收尾） |
| `t` / `d` | 是 | 标题 / 正文，支持 `<b>` 加粗；正文可写读法引导（先看什么、再看什么） |
| `exclude` | 否 | 选择器数组：在高亮区内再"挖掉"一块（如整行高亮但排除其中一张跨行大卡，给它单设一站） |
| `pad` | 否 | 挖孔外扩像素，默认 8 |

### 行为要点

- 挖孔坐标按基座等比缩放换算，任意窗口尺寸准确；蒙层用 `box-shadow: 0 0 0 4000px` 实现" mask 挖洞"。
- 导读卡自动避让：下 → 上 → 右 → 左，都放不下贴边缩放（0.55 起）。
- 右上角自动注入「看板导读」按钮：有 `.h-right` 放进去，否则固定右上。
- 文案可编辑：卡内「编 辑」→ 保存 localStorage（key = `dvTour-<页面标题>-v<lsVersion>`）；「恢复默认」还原。
- 键盘：Enter / → 下一步，← 上一步，Esc 关闭。API：`window.TourAPI.{show,close,next,prev}`。
- 高亮目标加 `id` 或稳定 class；导读站数 5–9 站为宜，每站只讲一个版块或一条竖读线。
- 含地图页面：地图宜单独设一站；整行高亮但需排除地图时用 step 的 `exclude` 补蒙层。

## 3+. 地图光点（大屏地图.js）

接入写法、底图素材询问规则、拖拽/连线/飞线行为与自测见 `地图板块.md`。与本文件其他能力的叠加关系：

- 地图板块与编辑/导读同页共存，互不冲突（光点 `dblclick` 已阻断，不触发全屏）。
- 光点位置持久化 key = `dvMap-<页面标题>-v<lsVersion>`；换底图/改投影后 `lsVersion` +1。

### 导读文案写法（与内容叙事方法对齐）

- 开篇站：一句话叙事 + 全屏读法（"横读是层级，竖读是业务域"）。
- 版块站：这个版块回答什么问题 + 1–2 个关键读数。
- 竖读/收尾站：串一条主线（决策看什么 → 业务看什么 → 一线看什么）。

## 4. 与基座其他交互的关系

| 基座能力 | 来源 | 与两能力的关系 |
|---|---|---|
| 双击全屏 | 大屏基座.js | 编辑/导读均 stopPropagation，互不误触；全屏时导读照常可用 |
| 数字滚动 | 大屏基座.js（`data-num`） | 导读文案里引用的数字要与 `data-num` 目标一致 |
| 时钟 | `.js-clock` | 无交互 |
| 列头/层标显隐 | 页面自带 | 导读高亮计算按当前 DOM 实时取矩形，显隐后重开导读即正确 |

## 5. 交付前自测（浏览器）

1. 直接双击打开 HTML：缩放居中、无横向滚动条。
2. 双击任一面板标题 → 可编辑，Esc 还原；双击空白处 → 进全屏。
3. 右上角「看板导读」→ 逐站挖孔位置正确、卡片不遮高亮区、编辑后刷新仍生效。
4. 缩放浏览器窗口（含非 16:9）→ 挖孔与卡片跟随不出位。
5. 含地图页面 → 光点可拖拽且连线/飞线实时跟随；刷新后位置保留；「重置」复原；点击光点与卡片联动。
