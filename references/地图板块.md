# 地图板块（光点地标 · 拖拽 · 卡片连线）

> 能力由 `assets/大屏地图.js` 提供（配置驱动），骨架同方案：光点脉冲地标 + 拖拽微调（localStorage 持久化）+ 光点↔卡片虚线连线 + 光点间飞线弧 + 16:9 等比适配居中裁切。
> **涉及地图的方案，确认环节必须先向用户要底图素材**（见 §1），不要自行臆造地理底图。

## 1. 底图素材：先问，再动手

布局含地图（L3 或任何带地理分布的版块）时，在 AskUserQuestion 或追问里向用户确认：

1. **地理范围**：全国 / 省份 / 区域 / 全球？涉及哪些地标点（城市、园区、数据中心、门店）？
2. **素材形态**（按优先级）：
   - 用户已有**底图图片**（png/jpg，深色科技风优先）→ 直接挂背景；
   - 用户有 **GeoJSON/地图数据** → 按数据用 `d3-geo` 等真实投影渲染（一次性生成时可直接预投影成静态 SVG 路径写进页面，保持零依赖）；
   - 都没有 → 询问是否接受**回退方案**：深色渐变底 + 光点示意（S3），方案 md 标注「底图待替换」，绝不画手绘假地图冒充真实地理。
3. **投影一致性**：给图片底图配经纬度光点时，图片必须是标准 Web 墨卡托裁切（如地图工具导出的轮廓图）；否则让光点直接用百分比坐标（`x/y`），或让用户标注底图四角的经纬度。

## 2. 页面接入

```html
<div class="map-wrap">                 <!-- cfg.wrap：内容区，铺满连线 SVG -->
  <div class="dc-list">
    <div class="dcard" data-dmk="a">…</div>   <!-- 联动卡：data-dmk 绑光点 -->
    <div class="dcard" data-dmk="b">…</div>
  </div>
  <div id="geoBox"></div>              <!-- cfg.box：JS 控制尺寸，底图挂它背景 -->
</div>
<script>
window.DVMAP = {
  wrap: '.map-wrap', box: '#geoBox', reset: '#mkReset', lsVersion: 1,
  fit: {ratio: 16/9},                  // 高度铺满、宽=高*16/9、居中裁切
  projection: {center: [33.6, 104.6], zoom: 4.75, scale: 1.3},
                                       // scale 与底图 background-size:(scale*100)% 严格对应，改一处同步另一处
  markers: [
    {k:'a', lat:39.9, lng:116.4, c:'#35D6FF', label:'点A', tip:'…'},
    {k:'b', x:62, y:70,          c:'#FFC24A'}   // 无投影时直接百分比坐标
  ],
  arcs: [['a','b']],                     // 飞线弧（可选）
  arcStroke: 'rgba(90,225,255,.45)',     // 弧线颜色（可选，深底默认）
  linkStroke: 'rgba(53,214,255,.55)'     // 连线颜色（可选；浅底大屏加深，如 rgba(22,104,220,.5)）
};
</script>
<script src="大屏地图.js"></script>
```

引用顺序：`大屏基座.js` → `window.DVMAP` 配置 → `大屏地图.js`（与编辑/导读并列，可同页共存）。

> 浅底风格（S3）注意：地图面板若保留深色底（浅底大屏的常见「深色锚点」手法），光点用提亮语义色（#2BE3A4/#FFC24A/#FF5D73）；卡片在浅色区，`linkStroke` 需换深色（如 `rgba(22,104,220,.5)`）才能看清。

## 3. 行为清单（交付前按此自测）

| 能力 | 行为 |
|---|---|
| 光点 | 脉冲圆点（`--c` 控色），可选 `label` 芯片、`tip` 悬停提示 |
| 拖拽 | pointer capture 拖拽微调；范围钳制（x 2~98%、y 6~94%）；松手存 localStorage（key 含页面标题 + lsVersion）；拖动中飞线弧与连线实时跟随 |
| 连线 | 每个 marker 自动找 `wrap` 内 `[data-dmk="k"]` 卡片，画右缘中点→光点的虚线贝塞尔；卡片不在或不匹配则跳过 |
| 联动 | 点击光点或卡片：所有 `[data-dmk="k"]` 元素加 `.on`（高亮样式页面 CSS 自定），并触发 `onSelect` 回调 |
| 适配 | 容器尺寸变化（ResizeObserver/resize）→ 重算 16:9 尺寸并重画 |
| 重置 | `cfg.reset` 指向的按钮清 localStorage 并回到投影/配置位置 |
| API | `window.DvMapAPI.{select(k), reset(), redraw()}` |

## 4. 样式与排版约定

- 光点层 z-index 5、连线层 10、导读层 80：三者互不遮挡；光点 `dblclick` 已阻断，不会误触基座全屏。
- **联动卡（节点卡）默认叠放在地图面板上层**（绝对定位左上，半透明深色 HUD 底，盖住地图空白区），不单独占地图外一列；`cfg.wrap` 指向包含卡片与 `geoBox` 的同一面板。
- 光点标签芯片文字默认固定浅色 `#EAF6FF`（芯片在深色底上），可用 CSS 变量 `--dv-map-label` 覆盖；不要让它跟随页面 `--text-1`，否则浅底主题下会深底深字不可读。
- 底图建议深色轮廓 + 微发光；卡片列与地图同处一个 `wrap`，连线才有正确坐标。
- 光点数量 3~12 个；带 `label` 时注意边缘光点的芯片会伸出地图，靠 `x/y` 预留边距。
- 换底图或改投影参数 = 坐标体系变化：`lsVersion` +1 弃用旧拖拽位置（同导读的版本规则）。

## 5. 与其他能力的关系

- **导读**：地图可单独设一站（光点密集不宜与别的高亮合并）；若整行高亮需排除地图，用导读 step 的 `exclude` 补蒙层。
- **双击编辑**：卡片标题照常可编辑；光点 `label` 走配置，不走编辑。
- **示例数据**：地标名/坐标用用户业务真实地点或明显示意名，不臆造真实感地名（遵守技能红线）。
